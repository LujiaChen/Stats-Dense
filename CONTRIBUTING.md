# Contributing to Stats Dense

Open issues and pull requests in this repository for Dense-specific behavior. Include your macOS version, Mac/chip model, application version, enabled modules, selected display mode, and clear reproduction steps. Redact serial numbers, account details, IP addresses, and unrelated desktop content from attachments.

The current Dense layout intentionally contains five fixed metrics. Requests for configurable slots are welcome as future feature proposals, but are not supported by the current release.

Keep changes focused on presentation and reuse upstream readers. Avoid polling timers, animated status-item resizing, private window-management APIs, and overflow workarounds. Test 9%, 10%, and 100% with missing readings and both appearances. A successful build does not replace runtime validation.

For a problem that also affects official Stats, reproduce it with the official build before contacting the upstream project. Do not send fork-only issues to the upstream maintainer.
